# Worldgen v2 — organic villages, clustered ground, social placement

Date: 2026-09-28. Branch: `feat/living-agents-phase1`.

Three independent upgrades to the procedural town, chosen after surveying MarkovJunior,
WFC/DeBroglie, ASP, Watabou and Emilien et al. 2012 (see conversation log). None of
those is a drop-in library for a semantic, tile-based TS town; we take ideas, not code.

| Track | What | Why |
|---|---|---|
| A | Noise-clustered terrain + Poisson-spaced trees; autotiled road/dirt edges | Ground is uniform 13% salt; roads are hard-edged boxes |
| B | Assign `Home N` plots from the social graph | House distance already drives sim encounters (walk time, 640/(640+d) venue penalty, nearest-friend visits, 80px perception) — so placement creates stories |
| C | `layoutStyle: 'organic'` — Emilien-style interest map → settlement seeds → grown lanes | Every town has the same 2H+2V skeleton today |

## Ground rules (all tracks)

- `npm run check` green before and after. Tests pinned by determinism stay deterministic.
- Worldgen modules stay pure (client imports them): no Node/DB imports under `server/lib/worldgen/`.
- **Default output for existing configs must not change except where a track says so.**
  Track B with no social input and Track C with `layoutStyle: 'grid'` must be byte-identical
  to today (same seed → same `GenResult`). Track A intentionally changes `terrainTiles`.
- Only `FitError` for spatial failures (pipeline grows the map on it).
- Contracts kept: south-centre doors `(x + w/2, y + h)`, unique location names, `Home N`
  names, `mainstreet` is an axis-aligned rect overlapping no other location, every entry
  tile walkable and mutually reachable, `BORDER_BUFFER`/`ROAD_BUFFER`/`BUILDING_GAP`.
- Comments explain *why*, matching the codebase's long-rationale style. English.

## Stage 1 — parallel (separate worktrees)

### A1. Terrain generation (`server/lib/worldgen/`)
- New `noise.ts`: seeded 2D value noise with fBm (octaves, lacunarity, gain) built from an
  `RNG` (permutation table from `rng.shuffle`), and `poissonDisk({width, height, radius, mask?, accept?, rng, maxTries?})` (as built: options object; reseeds per mask island)
  (Bridson, tile grid, respects a Uint8Array mask). Pure, deterministic, unit-tested.
- Rewrite `stages/terrain.ts` scatter (keep the occupied mask logic verbatim):
  - Kinds emitted: `flowers`, `grass_tuft`, `dirt_patch`, `tree`, `bush`, `rock`.
    `tall_grass` is **legacy** — no longer emitted, still rendered for old saved worlds.
  - Flowers/grass tufts/dirt come in noise-shaped clusters (as built: top-N ranking of each noise field, so per-world shares are stable) (meadows, worn patches).
  - Trees via Poisson disk (radius ≈ 2.5–3 tiles) inside "grove" noise regions, denser toward
    the map border and ≥ 2 tiles from any road/footprint/door; bushes as grove fringe; rocks
    sparse, mostly on dirt.
  - Total decorated share of eligible tiles in [0.10, 0.22]. Clustering test: for flowers and
    dirt, P(has same-kind 4-neighbour) ≥ 0.35 (uniform scatter is ~0.05–0.2).
- Update `terrain.test.ts` (density band, kinds, clustering, tree spacing ≥ radius, never on
  road/footprint/door, determinism) and add `noise.test.ts`.

### A2. Renderer autotiling (`src/`)
- New pure `src/lib/autotile.ts`: 8-neighbour bitmask for a tile set; helpers returning which
  edges are exposed, which outer corners to round and which inner (concave) corners to fill;
  merge a tile set into blob outlines for dirt. Unit test `src/lib/__tests__/autotile.test.ts`.
- `TilemapRenderer.setRoadTiles`: rounded outer corners, inner-corner fills, a 2px dithered
  edge (art bible: "2px noise dither at edges"); ruts must also look right on bends and
  L/T junctions (Track C lanes bend; staircase diagonals must not look like confetti).
- `setTerrainTiles`: render the new kinds (`grass_tuft`, `tree`, `bush`, `rock` explicitly —
  reuse `drawTree/drawBush/drawRock`), keep `tall_grass` legacy branch unchanged; draw
  contiguous `dirt_patch` tiles as merged soft blobs instead of per-tile ellipses.
- `WorldPreview.tsx`: colours for the new kinds.
- Keep it within the art bible (muted earth tones, terrain in background) and draw-call
  budget (one Graphics per layer, no per-tile containers for props).

### B. Social home placement
- `server/lib/worldgen/social.ts` (pure): `SocialEdge = { a: string; b: string; kind:
  'rival' | 'secret_lovers' | 'lovers' | 'friends' }` (agent names) and
  `buildSocialEdges(relationships, scenario, agents)` classifying:
  rival (status rivals/enemies, tags rival/grudge/antagonist, scenario `rivalPairs`),
  secret_lovers (romance threads `secret_fling`/`forbidden` only — other threads with a secret row are not affairs),
  lovers (mutual romance ≥ 40 — see `LOVERS_THRESHOLD`; no template reaches 50 both ways), friends (mutual friendship ≥ 50).
- `GenerateOptions.social?: { edges: SocialEdge[] }` → `StageExtras`; config
  `socialPlacement: boolean` (default true) in `WorldGenConfigObjectSchema` + client mirror.
- `homes.ts`: plot selection unchanged. Afterwards compute a permutation mapping home labels
  to chosen plots minimising: rivals → near (Manhattan door distance), friends/lovers → near
  (lower weight), secret lovers → far (reward distance, capped), agent's workplace → mildly
  near. Deterministic pairwise-swap hill climb (bounded iterations, fixed sweep order, no rng — keeps the homes rng stream byte-identical).
  No edges or `socialPlacement: false` → identity permutation (byte-identical output).
- `setup.ts`: compute `buildScenario` **before** `generateWorld` in `replaceWorld` and pass the
  same object into `seedWorld` (no double computation); `previewWorld` accepts optional
  `relationships` + `scenario` so the wizard preview matches Start; `WorldLayout.tsx` sends
  them (and includes them in the refresh deps). `db/seed.ts` passes the seed relationships.
- Tests: rivals end closer than the median home pair, secret lovers farther, determinism,
  no-social = identical to baseline, `socialPlacement:false` = identical, housemates unaffected.

## Stage 2 — C. Organic layout (after A1 merged; uses `noise.ts`)
- Config `layoutStyle: 'grid' | 'organic'` (default `grid`) in schema, client mirror,
  `SetupConfigSchema` default, `previewWorld` input, `WorldLayout.tsx` dropdown + deps.
- `RoadsOutput.mainStreet?: {x, y, width, height}` (tiles). `deriveMainstreet` uses it when
  present (fixes the latent bug of spanning min/max x across unrelated runs on the same row);
  grid mode keeps its current output.
- Organic `roads` stage (rng now used; fork label stays `roads`):
  1. Interest map = fBm noise + centre falloff.
  2. Straight 2-wide horizontal main street, 50–70% of width, y jittered around mid-height.
  3. K settlement seeds (K from map area/agent count) sampled by interest with min spacing.
  4. Grow outward: connect seeds nearest-first to the existing network with A* over a cost
     field (noise cost, turn penalty, strong discount on existing road), then dilate to 2 wide.
  5. Zones: rect cell grid over the inner map (unique ids) with affinities from the interest
     map / distance to main street (commercial & mainStreet near it, civic near centre,
     residential elsewhere) so `layout.ts`/`homes.ts` work unchanged.
- Tests: all layout/homes/pipeline/property invariants re-run for `organic` over many seeds
  (overlap, reachability, door-to-road shares, core templates placed at 60×45, determinism,
  road inside border buffer, road network connected), plus "organic differs from grid".
- As built (track C): `stages/organicRoads.ts`. Lanes are 2×2 stamps of a Dijkstra path over
  (cell, heading) with turn, noise, near-road (radius 8) and 2× north/south step costs (south
  doors front east-west lanes); ~10 seeds at 56×43 (area/240); one loop-closing link when a short
  one exists (~98%). Deviations: zone rows are cut *at the main street* (a 10-row band north of
  it) instead of an even grid, plus a zero-affinity whole-map fallback zone appended last —
  without them the town square often had no frontage and the farm occasionally no zone. A
  first-fit "lot guard" skips lanes that would leave no room for the town's templates (0 map
  growth in 800 seeds at 1/5/13 agents). `deriveMainstreet` without a hint now spans the longest
  contiguous run. Grid is byte-identical (640 worlds; 32 hashes pinned in `organic.test.ts`).
