## Tooling

- **Aseprite pipeline** (`D:\SteamLibrary\steamapps\common\Aseprite\Aseprite.exe`, 1.3.18): every
  sprite set is a batch Lua script that writes `.aseprite` sources + the PNG the client loads.
  Re-run after editing: `Aseprite.exe -b --script-param dir=<out> --script scripts/aseprite/<x>.lua`.
  `agent-sheets.lua` (derives 11-frame sheets from `public/sprites/agents/<name>.png`),
  `roof-tiles.lua`, `nature-props.lua`, `furniture.lua`, `emotes.lua`, `beat-fx.lua`,
  `held-items.lua`, `event-decor.lua`, `critters.lua`, `portrait-moods.lua`. Every script's frame
  order is mirrored in a `*Frames.ts` table next to its consumer — keep them in sync.
- **Canvas systems** (`src/components/canvas/systems/`): pluggable per-feature renderers, one line
  each in `systems/index.ts` (contract in `systems/types.ts`). `?nosystems` in the URL disables them
  all for A/B frame-time checks; `node docs/scratch/probe-living-canvas.mjs` (verify server running)
  triggers an event + an intervention, samples fps and lists atlas loads and console errors.

- `npm run check` — gate (tsc + vitest).
- `npm run deadcode` — orphan files / unused exports.
- `npm run soak -- --days 5 [--tick-speed 4] [--db data/verify.db]` — headless multi-day run with
  the LLM disabled (template tier), on a temp DB copy; prints a daily economy table and flags
  anomalies. Refuses `data/little-life.db`. ~2 min per game day at speed 1.
- Playtest recipe (real LLM): copy `data/little-life.db*` → `data/verify.db*`, run the server with
  `DATABASE_PATH=./data/verify.db`, sample the DB read-only. See CLAUDE.md "Live verification".

## DB migration note

`server/db/clockMigration.ts` rebases old tick stamps to game minutes once per DB file
(`PRAGMA user_version` 0 → 2) the first time any process opens it through `server/db`. Verified on a
copy of the live world (tick 15 → stamps 1981/1980, second run no-op). Backup taken before the
change: `data/backup-2026-09-29-pre-gameclock/`. Running **old** code against a migrated DB would
write tick stamps into minute columns — don't switch back to pre-2026-09-29 branches on the same DB.
